# Security policy

PocketRemote lets a phone control a desktop session, so a vulnerability can mean full control of someone's computer. Please report problems privately.

## Reporting a vulnerability

Use GitHub private vulnerability reporting: open the repository's **Security** tab and choose **Report a vulnerability**. Do not open a public issue or pull request for a security problem.

Please include the affected version, what you did, what you expected and what happened. Never include real keys, pairing tokens or screenshots of QR codes.

## Scope

In scope: pairing, session encryption and authentication, network exposure, input limits, key storage, the release pipeline.
Out of scope: malware already running on the computer or the phone (see `docs/security.md`).

## Supported versions

Only the latest release is supported.
